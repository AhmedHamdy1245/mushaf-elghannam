================================================================
مشروع تطبيق أندرويد: المصحف الشريف
صدقة جارية على روح الدكتور/ محمود محمد فؤاد الغنام (رحمه الله)
================================================================

هذا المجلد يحتوي على مشروع أندرويد كامل وجاهز لإنتاج ملف APK.

الطريقة الأولى (عبر Android Studio على جهازك):
1. فك ضغط الملف المضغوط mushaf_quran_android_project.zip.
2. افتح برنامج Android Studio واختر Open ثم حدد هذا المجلد.
3. من القائمة العلوية اختر: Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ستجد ملف التطبيق الجاهز في المسار:
   app/build/outputs/apk/debug/app-debug.apk

الطريقة الثانية (بدون تثبيت Android Studio — عبر GitHub مجاناً):
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub وارفع ملفات هذا المجلد إليه.
2. افتح تبويب Actions داخل المستودع واضغط على Build Android APK ثم Run workflow.
3. بعد دقيقة تقريباً ستجد ملف APK جاهزاً للتحميل من قسم Artifacts باسم mushaf-elghannam-apk.
